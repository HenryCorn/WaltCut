# WaltCut Roadmap

WaltCut is a small, native macOS editor for 2D hand-drawn animation: import footage, images and
audio, arrange a simple timeline, draw and manage cels, preview, export. The scope is described
in [docs/animation.md](docs/animation.md). It is not a general-purpose editor.

Epic [#14](https://github.com/HenryCorn/WaltCut/issues/14) removes everything outside that scope.
The detail is in [docs/roadmap.md](docs/roadmap.md).

## Stages

| Stage | What | Status |
|---|---|---|
| Reduce | Delete functionality outside the animation workflow (epic #14) | in progress |
| Rename | Crates, binaries, product name and `.waltcut` project extension | crates done; product rename pending |
| Release | v0.1.0, unsigned arm64 macOS build | pending |
| Animation depth | Reference images as onion paper ("tracing paper"), storage panel, showcase video | pending |
